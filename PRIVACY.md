# Your journal stays with your files

The local interface contains no analytics, remote font load, provider request, wallet extension call or transaction signing. It stores the active journal in browser local storage when available. Source mode fetches project files from its loopback server; the offline edition embeds them.

Local storage is not encrypted and can be inspected by someone with access to the browser profile. Exported files contain the reasons, allocations, observations and owner notes you recorded. Clear the active copy with a new empty journal when appropriate; this does not remove downloaded backups.

Sharing a review packet with Grok Bot transfers its contents into that account's task context. Review it before sharing. Source events can contain contextual notes and source IDs. The current packet includes the full case history, not just the latest passing values.

No secret or signing key is needed. Do not put keys in evidence notes. Public GitHub uploads should contain the supplied reference records or deliberately public research, not private position history.
