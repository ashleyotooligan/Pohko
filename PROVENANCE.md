# Original Pohko artwork and numerical figures

## Mascot

`pohko.png` was generated for this project on 1 November 2026 using the built-in image-generation tool. No earlier project character or reference image was supplied. The original image is included without raster edits. It depicts a lilac creature with a stepped snout, orange feet and a three-tab tail on a warm plain background.

The mascot is decorative branding. It does not encode a market reading, a cognitive state or a measured condition. It is independent of provider logos and has no claimed official affiliation.

## Exact final prompt

Use case: logo-brand. Asset: original 8-bit mascot for a new Solana thesis-memory project called Pohko. Make a completely original small pixel creature: a squat lilac-purple tapir-like pocket archivist with a long downward-stepped rectangular snout, two tiny sleepy black square eyes, small rounded-square ears, a heavy pear-shaped body, and four short tangerine feet. Its enormous upright tail is a fan of exactly three staggered wide rectangular lilac panels like index-card tabs, part of its anatomy. The character stands in three-quarter side view facing left. No clothes, no held objects, no book, no coins. Cute, thoughtful, sturdy, slightly odd; strong instantly recognizable silhouette. Authentic retro 8-bit pixel sprite, bold deliberate square pixels on roughly a 64x64 logical grid, clean stair-stepped contours, minimal dark aubergine outline, flat clustered shading, limited palette of lavender, deep plum, ivory and tangerine. Plain solid warm off-white background #f5f1e8, generous space around the centered full-body character. Square image. No letters, no text, no wordmark, no border, no glow, no gradients, no 3D, no soft shadows, no scenery, no watermark. Entirely new design, not a goblin, robot, fly, brain or paper-fold mascot.

## Cover and journal views

`capture.mjs` composes the cover and twelve numbered figures with native Canvas using the same `views.mjs` renderer as the local interface. Values come from the verified reference journal and implemented evaluator. Typography, layout, plots, digest strings and tables are generated by code. They are not image-model approximations or provider UI screenshots.

The reference journal is an authored example record. Every figure retains the origin and connection boundary. The character is the only image-model artwork used in the project. No stock sprites, chain logo or other project's asset is included.
