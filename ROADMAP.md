# Work that follows the journal

## Established in 0.1.0

Owner-authored entries; one to three declared conditions; per-source recency; freshness and contradiction states; explicit amendments; owner reviews and closure; linked event digests; local persistence; validated imports; five exports; twelve research views; a user-managed Grok Bot operator pack.

## Next useful extensions

- A full in-browser condition editor with version comparison and explicit evidence reset.
- Evidence import adapters that retain the exact provider response, metric definition and observation clock.
- Source identity and shared-upstream annotations, with no implied independence from ID count alone.
- Signed owner events and an independently stored head for stronger attribution and replacement detection.
- Optional network anchoring of a digest, with actual transaction status and explorer evidence kept separate from the review result.
- Account-side handoff transport that records a real task result instead of only a prepared file.
- Keyboard and screen-reader alternatives to the full visual evidence page.

These items require separate implementation and validation. Their descriptions are not active connection claims in this release.
