# Upload the whole folio

Every project file is in one flat `pohko` folder. There are no subfolders to skip.

1. Extract `Pohko-GitHub.zip` and open the inner `pohko` folder.
2. Create a repository under your chosen account. Name it **pohko**. Leave automatic README/license/gitignore generation off because they are supplied.
3. Choose **Add file → Upload files**.
4. Select every file inside the extracted folder with Ctrl+A, then upload the selection.
5. Confirm that `README.md`, `pohko.png`, `pohko-cover.png` and all twelve numbered PNGs appear at the repository root.
6. Commit the upload.
