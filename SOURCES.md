Pohko's role instructions, data format, evaluator and visuals are original project material. The provider docs support the account-side workflow description; they do not certify this repository or its research results.

The name is a nod to Proof of History. The project does not reproduce a consensus mechanism. Its local journal hashes should not be described as Solana confirmations. The allocation unit is SOL; fictional asset labels in the reference file do not identify real mints.

There is no provider SDK, market indexer, wallet connector, deployment address or network execution receipt in the shipped code. Further adapters need an explicit data contract and evidence of their own successful operation.
