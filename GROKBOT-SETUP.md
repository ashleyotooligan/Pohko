# Set up Pohko as a research role

Pohko supplies project-authored instructions and review files. Its transport is a user-managed file handoff in your own Grok Bot account. No account is connected by this repository.

1. Create or choose a named Bot through the provider's account interface.
2. Provide [GROKBOT-OPERATOR.md](GROKBOT-OPERATOR.md).
3. Export a current review JSON from Pohko and attach it.
4. Use [GROKBOT-REVIEW.md](GROKBOT-REVIEW.md) for one manual pass.
5. Inspect the returned note against the packet, including cutoff, original reason, condition states and event references.
6. Only after a correct pass, adapt [routine wording](GROKBOT-ROUTINE.md) to a source location, cadence, time zone and output location in your account.

Grok Bot's official documentation describes named persistent Bots and reusable skills/routines. Those provider capabilities are separate from Pohko's local arithmetic and file contracts. References were checked on 1 November 2026 and are listed in [SOURCES.md](SOURCES.md).

Ask for `pohko-research-note.md` with an opening finding, facts table, original-versus-current reason, unresolved evidence and source event IDs. Do not describe a locally prepared packet as a completed provider result. Keep the returned interpretation outside the journal until you decide to append an owner review.

The deterministic local note export is available without an account and identifies itself as a local rule report. It is not a transcript or response from Grok Bot.
